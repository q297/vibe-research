# Новостная аналитика для Альфа-Бизнеса (прототип)

Сервис отбирает новости для конкретной компании и объясняет, что они значат для её бизнеса, с учётом аналитики Альфа-Банка.

> Сейчас работает каркас на синтетических данных (`MOCK_MODE=true`): ingestion, ранжирование и агент заменены заглушками. Контракты описаны в [docs/contracts.md](docs/contracts.md).

## Структура

```
backend/    FastAPI BFF, контракты (Pydantic), заглушки модулей, тесты
frontend/   React + Vite + Tailwind: главная с виджетом, лента, карточка инсайта, трасса, чат
docs/       openapi.json, JSON Schema, описание контрактов
```

## Быстрый запуск (Docker)

```bash
cp .env.example .env
docker compose up --build
```

Интерфейс: http://localhost:8080, Swagger: http://localhost:8080/api/docs

## Локальная разработка

Нужны [uv](https://docs.astral.sh/uv/) и Node.js 24.

```bash
make install
make dev-api   # http://localhost:8000/docs
make dev-web   # http://localhost:5173
make test
```

Без `DATABASE_URL` данные BFF хранятся в памяти и пропадают при перезапуске. В Docker используется Postgres: миграции из `backend/migrations` применяются при старте контейнера `api`.

## Демо-учётки

Учётки и пароли лежат в `backend/app/stubs/fixtures/users.json`. Это тестовые данные, не используйте их на публичном стенде без смены паролей.

| Логин | Кто | Доступ |
|---|---|---|
| `demo` | демо-администратор | все три компании, переключатель клиента |
| `cfo.a` | финансовый директор | компания A (металлургия, экспорт, кредиты) |
| `ceo.b` | генеральный директор | компания B (ритейл, без долга) |
| `treasurer.c` | казначей | компания C (агрохолдинг, ВЭД) |

## Сценарий проверки (на заглушках)

1. Войти как `demo`. На главной виден блок «Новости для вашего бизнеса».
2. Переключить клиента в шапке: лента меняется, у каждой новости есть чипы «Почему вам».
3. Открыть новость: агент показывает шаги в панели «Как получен вывод», затем появляется карточка с бейджами «Факт / Позиция Альфа-Банка / Вывод AI».
4. Для компании C открыть новость про пошлину на пшеницу: критик не находит позицию банка, и агент делает повторный поиск.
5. Задать вопрос в чате, поставить 👍/👎.
6. Открыть «Своя новость», вставить любой текст длиннее 40 символов: новость классифицируется, агент строит инсайт, а утверждения из текста помечены «Из введённого текста».
7. Открыть «Качество»: число инсайтов, оценки, доля самокоррекции, время построения. После `docker compose restart api` данные на месте.
8. Войти как `cfo.a`: другие компании недоступны (ответ 403), раздела «Качество» нет.
